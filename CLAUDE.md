# Project

You are working on pseyosc, a cross-platform utility that handles Playstation 3 Eye Cameras and Move-Motion Controller (including detection and pairing controllers), converting their data into OSC signals.

# Information

Read doc/DevelopmentNotes.md first: it collects the technical decisions, findings, psmoveapi workarounds and open work.
